# وب‌سایت شخصی بهمن دانش

این سایت یک وب‌سایت استاتیک است و برای انتشار عمومی به سرور اختصاصی یا پرداخت هزینه نیاز ندارد.

## انتشار رایگان با GitHub Pages

1. وارد حساب GitHub خود شوید و یک مخزن عمومی با نام دقیق `babiabsolut-arch.github.io` بسازید (اگر این نام متعلق به حساب دیگری است، نام کاربری واقعی خودتان را جایگزین کنید).
2. تمام فایل‌ها و پوشه‌های داخل این بسته را در شاخه `main` مخزن بارگذاری کنید؛ فایل `index.html` باید در ریشه مخزن باشد.
3. در مخزن، به مسیر **Settings → Pages** بروید.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید؛ شاخه `main` و پوشه `/(root)` را تعیین و ذخیره کنید.
5. چند دقیقه بعد سایت از نشانی `https://USERNAME.github.io/` در دسترس خواهد بود.

## به‌روزرسانی خودکار فهرست PubMed

فایل `.github/workflows/update-feed.yml` هر روز اجرا می‌شود. برای فعال‌کردن آن، در **Settings → Actions → General → Workflow permissions** اجازه نوشتن محتوا (Read and write permissions) را فعال کنید. اجرای دستی هم از زبانه **Actions** ممکن است.

## پیش از انتشار

- در `index.html` نشانی ایمیل واقعی و لینک شبکه اجتماعی خود را جایگزین متن‌های راهنما کنید.
- نشانی canonical و `og:url` را با دامنه واقعی خود تطبیق دهید.
- عنوان و معرفی حرفه‌ای را با وضعیت تحصیلی/مجوز حرفه‌ای واقعی خود هماهنگ نگه دارید؛ تا پیش از اخذ مجوز، خود را پزشک دارای پروانه معرفی نکنید.

## هزینه

GitHub Pages برای این نوع وب‌سایت عمومی و استاتیک رایگان است. خرید دامنه اختصاصی اختیاری است؛ آدرس پیش‌فرض `github.io` رایگان می‌ماند.
